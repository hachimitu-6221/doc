## `setp`

使用关系运算符比较两个数值，并可以选择通过布尔运算符，将比较结果与另一个谓词值组合。
## 语法
```ptx
setp.CmpOp{.ftz}.type         p[|q], a, b;
setp.CmpOp.BoolOp{.ftz}.type  p[|q], a, b, {!}c;
```

```ptx
.CmpOp  = { eq, ne, lt, le, gt, ge, lo, ls, hi, hs,
            equ, neu, ltu, leu, gtu, geu, num, nan };
.BoolOp = { and, or, xor };
.type   = { .b16, .b32, .b64,
            .u16, .u32, .u64,
            .s16, .s32, .s64,
                  .f32, .f64 };
```

## 描述

比较两个值，并可选择通过布尔运算符，将比较结果与另一个谓词值组合。最终结果写入第一个目标操作数。

使用比较结果的反值计算出的相关结果，会写入第二个目标操作数。

该指令适用于所有数值类型。操作数 `a` 和 `b` 的类型为 `.type`；操作数 `p`、`q` 和 `c` 的类型为 `.pred`。任意一个目标操作数都可以使用丢弃符号（sink symbol）`_` 代替。

## 语义

```ptx
t = (a CmpOp b) ? 1 : 0;
p = BoolOp(t, c);
q = BoolOp(!t, c);
```

其中：

- `t` 是 `a` 与 `b` 的比较结果；
- `p` 接收比较结果 `t` 与谓词 `c` 的布尔运算结果；
- `q` 接收比较结果的反值 `!t` 与谓词 `c` 的布尔运算结果。

## 整数说明

有符号和无符号比较运算符包括：

```text
eq、ne、lt、le、gt、ge
```

对于无符号值，还可以使用以下运算符：

| 运算符 | 含义 | 可替代的运算符 |
|---|---|---|
| `lo` | 低于（lower） | `lt` |
| `ls` | 低于或相同（lower-or-same） | `le` |
| `hi` | 高于（higher） | `gt` |
| `hs` | 高于或相同（higher-or-same） | `ge` |

对于无类型、仅按位宽比较的操作，可用的比较运算符为 `eq` 和 `ne`。

## 浮点数说明

有序比较运算符包括：

```text
eq、ne、lt、le、gt、ge
```

如果任一操作数为 NaN，则比较结果为 `False`。

为了在存在 NaN 时进行比较，还提供了相应的无序比较版本：

```text
equ、neu、ltu、leu、gtu、geu
```

- 如果两个操作数都是数值，即都不是 NaN，这些比较与对应的有序比较结果相同；
- 如果任一操作数为 NaN，这些比较的结果为 `True`。

此外：

- `num`：当两个操作数都是数值，即都不是 NaN 时，返回 `True`；
- `nan`：当任一操作数为 NaN 时，返回 `True`。

### 次正规数

**`sm_20` 及更高架构：**

- 默认支持次正规数；
- `setp.ftz.dtype.f32` 会将次正规输入刷新为保留原符号的零。

**`sm_1x` 架构：**

- `setp.dtype.f64` 支持次正规数；
- `setp.dtype.f32` 会将次正规输入刷新为保留原符号的零。

修饰符 `.ftz` 仅适用于 `.f32` 比较。

## PTX ISA 说明

在 PTX ISA 1.0 版本中引入。

## 目标 ISA 说明

源类型为 `.f64` 的 `setp` 指令需要 `sm_13` 或更高架构。

## 示例

```ptx
    setp.lt.and.s32  p|q,a,b,r;
@q  setp.eq.u32      p,i,n;
```
