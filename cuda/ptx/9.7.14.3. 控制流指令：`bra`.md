## `bra`

跳转到目标位置，并从该位置继续执行。
## 语法

```ptx
@p   bra{.uni}  tgt;           // tgt 是一个标签
     bra{.uni}  tgt;           // 无条件分支
```
## 描述
在目标位置继续执行。条件分支通过守护谓词（guard predicate）指定。分支目标必须是一个标签。

`bra.uni` 保证不会发生分支发散，也就是说，在当前正在执行该指令的 warp 中，所有活跃线程的守护谓词值和分支目标都必须相同。

## 语义

```ptx
if (p) {
    pc = tgt;
}
```

即：如果谓词 `p` 为真，就将程序计数器 `pc` 设置为目标标签 `tgt`，从该位置继续执行。

## PTX ISA 说明

- 在 PTX ISA 1.0 版本中引入。
- PTX ISA 2.1 版本中引入的“尚未实现的间接分支”，已从规范中移除。

## 目标 ISA 说明

所有目标架构均支持。

## 示例

```ptx
bra.uni  L_exit;    // 一致的无条件跳转
@q  bra      L23;   // 条件分支
```
