`uint32_t` 有 32 个二进制位，最低位编号为 0。PTX 规定不同位置存放不同配置。针对这里的 `.kind::f16`，相关字段如下：

| 位范围   | 含义      | 本例填入的字段值      | 表示什么             |
| ----- | ------- | ------------- | ---------------- |
| 4–5   | D 的数据类型 | `1`，二进制 `01`  | FP32             |
| 7–9   | A 的数据类型 | `1`，二进制 `001` | BF16             |
| 10–12 | B 的数据类型 | `1`，二进制 `001` | BF16             |
| 17–22 | N 的编码   | `32`          | N = 32 × 8 = 256 |
| 24–28 | M 的编码   | `4`           | M = 4 × 16 = 64  |

```
constexpr uint32_t dtype = 1u;  // FP32
constexpr uint32_t atype = 1u;  // BF16
constexpr uint32_t btype = 1u;  // BF16
// N 字段省略最低 3 位，M 字段省略最低 4 位：
constexpr uint32_t n_code = BLOCK_N / 8;   // 32
constexpr uint32_t m_code = BLOCK_M / 16;  // 4

constexpr uint32_t instruction_descriptor =
    (dtype  << 4)  |
    (atype  << 7)  |
    (btype  << 10) |
    (n_code << 17) |
    (m_code << 24);
```

指令描述符用于描述所有矩阵以及矩阵乘加运算的形状、数据类型和其他细节。它是寄存器中的一个 32 位值，具体布局取决于 MMA-Kind。
