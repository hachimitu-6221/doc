## `tcgen05.wait`

等待此前所有异步 `tcgen05.ld`／`tcgen05.st` 指令完成。

## 语法

```ptx
tcgen05.wait_operation.sync.aligned;
```

```ptx
.wait_operation = { .wait::ld, .wait::st }
```

## 描述

指令：

```ptx
tcgen05.wait::st
```

会使执行线程阻塞，直到该线程此前发起的所有 `tcgen05.st` 操作均已完成为止。

指令：

```ptx
tcgen05.wait::ld
```

会使执行线程阻塞，直到该线程此前发起的所有 `tcgen05.ld` 操作均已完成为止。

必需的 `.sync` 限定符表示：`tcgen05.wait_operation` 会使执行线程等待，直到 warp 中的所有线程都执行相同的 `tcgen05.wait_operation` 指令，然后才恢复执行。

必需的 `.aligned` 限定符表示：warp 中的所有线程必须执行相同的 `tcgen05.wait_operation` 指令。

## PTX ISA 说明

在 PTX ISA 8.6 版本中引入。

## 目标 ISA 说明

支持以下架构：

- `sm_100a`；
- `sm_101a`（从 PTX ISA 9.0 版本开始更名为 `sm_110a`）。

从 PTX ISA 8.8 版本开始，还支持以下特定架构家族：

- 同一家族中的 `sm_100f` 或更高架构；
- 同一家族中的 `sm_101f` 或更高架构（从 PTX ISA 9.0 版本开始更名为 `sm_110f`）；
- 同一家族中的 `sm_110f` 或更高架构。

## 示例

### 示例 1

```ptx
tcgen05.ld.sync.aligned.32x32b.x2.b32
    {r0, r1}, [taddr0];

// 防止后续 tcgen05.mma 抢在 tcgen05.ld 完成之前执行

tcgen05.wait::ld.sync.aligned;

tcgen05.mma.cta_group::1.kind::f16
    [taddr0], a-desc, b-desc, idesc, p;
```

### 示例 2

```ptx
tcgen05.st.sync.aligned.32x32b.x2.b32
    [taddr0], {r0, r1};

// 防止 tcgen05.mma 对 taddr0 的写入抢在 tcgen05.st 完成之前发生

tcgen05.wait::st.sync.aligned;

tcgen05.mma.cta_group::1.kind::f16
    [taddr0], a-desc, b-desc, idesc, p;
```
