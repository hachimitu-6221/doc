## `tcgen05.commit`

使 `mbarrier` 对象跟踪执行线程此前发起的所有异步 `tcgen05` 操作的完成状态。

## 语法

```ptx
tcgen05.commit.cta_group.completion_mechanism{.shared::cluster}{.multicast}.b64
    [mbar] {, ctaMask};

tcgen05.commit.cta_group.completion_mechanism.sync_restrict::shared::read::mma::a{.shared::cluster}{.multicast}.b64
    [mbar] {, ctaMask};
```

```ptx
.completion_mechanism = { .mbarrier::arrive::one }
.cta_group            = { .cta_group::1, .cta_group::2 }
.multicast            = { .multicast::cluster{::16b, ::32b} }
```

## 描述

`tcgen05.commit` 是一条异步指令。它使地址操作数 `mbar` 指定的 `mbarrier` 对象，跟踪执行线程此前发起的所有异步 `tcgen05` 操作的完成状态；这些操作如“基于 `mbarrier` 的完成机制”一节所列。

当被跟踪的异步 `tcgen05` 操作完成时，系统会在该 `mbarrier` 对象上触发 `.completion_mechanism` 指定的信号。该指令通过 generic 代理访问其 `mbarrier` 操作数。

指令：

```ptx
tcgen05.commit.cta_group::1
```

跟踪当前线程此前发起的、所有带有 `.cta_group::1` 的异步 `tcgen05` 操作的完成状态。

类似地，指令：

```ptx
tcgen05.commit.cta_group::2
```

跟踪当前线程此前发起的、所有带有 `.cta_group::2` 的异步 `tcgen05` 操作的完成状态。

同一个 kernel 中的所有 `tcgen05` 指令，必须为 `.cta_group` 限定符指定相同的值。

限定符 `.mbarrier::arrive::one` 表示：当前线程此前发起的异步 `tcgen05` 操作完成时，会在该 `mbarrier` 对象上发出一次 arrive-on 操作信号，其 `count` 参数为 1。该 arrive-on 操作的作用域为 cluster 作用域。

可选限定符 `.multicast::cluster` 允许向 cluster 中多个 CTA 的 `mbarrier` 对象发送信号。

操作数 `ctaMask` 指定 cluster 中的目标 CTA：16 位或 32 位 `ctaMask` 操作数中的每一位，分别对应目标 CTA 的 `%cluster_ctarank`。

附加子限定符 `::16b` 或 `::32b` 可用于指定 `ctaMask` 参数的宽度。默认情况下，`ctaMask` 被视为 16 位宽。

`mbarrier` 信号会被多播到每个目标 CTA 的共享内存中，其偏移量与 `mbar` 相同。

如果未指定状态空间，则使用通用寻址（Generic Addressing）。如果 `mbar` 指定的地址不在 `.shared::cluster` 状态空间的地址窗口内，则行为未定义。

带有 `.sync_restrict::shared::read::mma::a` 的 `tcgen05.commit` 操作，会在此前所有 `tcgen05.mma` 操作均已完成从共享内存读取矩阵 A 后，对 barrier 执行一次 arrive-on 操作。

**这并不表示此前的任何 `tcgen05.mma` 操作已经整体完成。**

## PTX ISA 说明

- 在 PTX ISA 8.6 版本中引入。
- `.sync_restrict::shared::read::mma::a` 限定符在 PTX ISA 9.4 版本中引入。
- 在 PTX ISA 9.4 版本中，引入对 `.multicast::cluster::16b` 和 `.multicast::cluster::32b` 限定符的支持。

## 目标 ISA 说明

支持以下架构：

- `sm_100a`；
- `sm_101a`（从 PTX ISA 9.0 版本开始更名为 `sm_110a`）。

从 PTX ISA 8.8 版本开始，还支持以下特定架构家族：

- 同一家族中的 `sm_100f` 或更高架构；
- 同一家族中的 `sm_101f` 或更高架构（从 PTX ISA 9.0 版本开始更名为 `sm_110f`）；
- 同一家族中的 `sm_110f` 或更高架构。

`.sync_restrict::shared::read::mma::a` 限定符支持以下特定架构家族：

- 同一家族中的 `sm_107f` 或更高架构。

`.multicast::cluster::32b` 限定符支持以下特定架构家族：

- 同一家族中的 `sm_107f` 或更高架构。

## 示例

### 示例 1

```ptx
tcgen05.cp.cta_group::1.128x256b
    [taddr0], sdesc0;

tcgen05.commit.cta_group::1.mbarrier::arrive::one.b64
    [mbarObj1];

loop:
mbarrier.try_wait.parity.b64 p, [mbarObj1], 0;
@!p bra loop;
```

### 示例 2

```ptx
tcgen05.mma.cta_group::2.kind::tf32
    [taddr0], adesc, bdesc, idesc, p;

tcgen05.commit.shared::cluster.multicast::cluster::32b.cta_group::2.mbarrier::arrive::one.b64
    [mbarObj2];

loop:
mbarrier.try_wait.parity.b64 p, [mbarObj2], 0;
@!p bra loop;
```

### 示例 3

```ptx
tcgen05.mma.cta_group::2.kind::tf32
    [taddr0], adesc, bdesc, idesc, p;

tcgen05.mma.cta_group::2.kind::tf32
    [taddr1], adesc1, bdesc1, idesc1, p1;

tcgen05.commit.cta_group::2.mbarrier::arrive::one.sync_restrict::shared::read::mma::a.b64
    [mbarObj2];
```
