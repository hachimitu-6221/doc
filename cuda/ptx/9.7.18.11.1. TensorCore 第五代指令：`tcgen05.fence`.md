## `tcgen05.fence`

用于异步 `tcgen05` 操作的专用 fence。
## 语法
```ptx
tcgen05.fence::before_thread_sync;
tcgen05.fence::after_thread_sync;
```
## 描述
指令：
```ptx
tcgen05.fence::before_thread_sync;
```
将此前所有的异步 `tcgen05` 操作，与其后的 `tcgen05` 操作及执行排序操作建立顺序关系。

指令：

```ptx
tcgen05.fence::after_thread_sync;
```

将此后所有的异步 `tcgen05` 操作，与此前的 `tcgen05` 操作及执行排序操作建立顺序关系。

`tcgen05.fence::*` 指令能够与同一线程作用域内的执行排序指令组合，并为该作用域内的 `tcgen05` 指令之间提供顺序保证。

`tcgen05.fence::before_thread_sync` 指令相当于此前 `tcgen05` 指令的代码移动屏障：此前的 `tcgen05` 指令不能被提升到该 fence 之后。

`tcgen05.fence::after_thread_sync` 指令相当于此后 `tcgen05` 指令的代码移动屏障：此后的 `tcgen05` 指令不能被提升到该 fence 之前。

## PTX ISA 说明

在 PTX ISA 8.6 版本中引入。

## 目标 ISA 说明

支持以下架构：

- `sm_100a`；
- `sm_101a`（从 PTX ISA 9.0 版本开始更名为 `sm_110a`）。

从 PTX ISA 8.8 版本开始，还支持以下特定架构家族：

- 同一家族中的 `sm_100f` 或更高架构；
- 同一家族中的 `sm_101f` 或更高架构（从 PTX ISA 9.0 版本开始更名为 `sm_110f`）；
- 同一家族中的 `sm_110f` 或更高架构。

## 示例

```ptx
// 生产者线程：

tcgen05.cp.cta_group::1.128x256b [taddr0], sdesc0;

tcgen05.fence::before_thread_sync;
st.relaxed.b32 [flag], 1;
```

```ptx
// 消费者线程：

loop:
ld.relaxed.b32 r, [flag];
setp.eq.u32 p, r, 1;
@!p bra loop;

tcgen05.fence::after_thread_sync;
tcgen05.mma.cta_group.kind [taddr0], adesc, bdesc, idesc, p;
```
