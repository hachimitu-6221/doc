通信原语：
- All-Reduce = Reduce-Scatter + All-Gather
	- Reduce-Scatter
		- 每卡输入大小 S，输出大小 S/N，**数据会收缩**。
	    - 和 Reduce 的区别：Reduce 把完整结果给一张卡，Reduce-Scatter 把结果**摊开**到所有卡。
	- All-Gather
		- 每卡输入大小为 S，输出大小为 N·S（N 为卡数），**数据会膨胀**。
		- 通信量主要来自“把别人的段收过来”，每张卡要接收 (N−1)·S。
```
卡0: [1  2  3  4]                          卡0: [10]        ← 第0段之和
卡1: [2  3  4  5]                          卡1: [20]        ← 第1段之和
卡2: [3  4  5  6]   ── Reduce-Scatter ─►   卡2: [30]        ← 第2段之和
卡3: [4  5  6  7]                          卡3: [40]        ← 第3段之和

卡0: [A]                            卡0: [A B C D]
卡1: [B]     ──── All-Gather ───►   卡1: [A B C D]
卡2: [C]                            卡2: [A B C D]
卡3: [D]                            卡3: [A B C D]
```
